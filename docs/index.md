# Documentation index

Research and design notes for running AI coding agents in sandboxes.

## Sections

- [Analysis](analysis/index.md) — reviews of agent harnesses, execution sandboxes, and cross-cutting comparisons and guides.
- `trials/` — local records of hands-on sandbox runs. Created by `smoketest.py --record` on your machine; gitignored, so absent in a fresh clone.
- [Guides](guides/index.md) — working methods that the agent skills follow, and [how-tos](guides/how-to/index.md) for running sessions, changing permissions and committing sandbox definitions.
